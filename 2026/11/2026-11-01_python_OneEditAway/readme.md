# One Edit Away

使用言語: Python
目安: 15〜25分

## 課題
2つの文字列が「1回以内の編集」で同じになるかを判定する関数
is_one_edit_away(a, b) を実装してください。

編集とは、次のいずれか1つを指します。
- 1文字の挿入
- 1文字の削除
- 1文字の置換

## 要件
1. 引数は半角英小文字のみの文字列とします。空文字列も渡されます。
2. 1回以内の編集で同じになる場合はTrue、それ以外はFalseを返してください。
3. 最初から同じ文字列の場合もTrueを返してください。
4. 外部ライブラリは使用しないでください。
5. main()で以下の入力例をすべて確認してください。

## 入力例と期待出力
a        b        戻り値
"pale"   "ple"    True
"pale"   "pales"  True
"pale"   "bale"   True
"pale"   "bake"   False
"same"   "same"   True
""       "a"      True
""       "ab"     False
"ab"     "ba"     False

※ 文字の入れ替えは1回の編集には含めません。

## ヒント
文字列の長さの差に注目してください。
それぞれの文字列を指す位置を用意すると、
挿入・削除・置換を区別して比較できます。

## 完了条件
上記の結果がすべて一致し、
空文字列同士でもTrueが返れば完成です。
