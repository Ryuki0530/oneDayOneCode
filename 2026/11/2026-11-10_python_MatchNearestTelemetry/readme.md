# MatchNearestTelemetry

使用言語: Python
目安: 15〜25分

## 課題

カメラ画像とサーボの電流値が別々の周期で記録されています。
各画像の撮影時刻に最も近い電流サンプルを対応付ける関数を実装してください。

## 実装要件

1. `match_nearest_telemetry(frame_times, samples, max_gap_ms)` を実装してください。
   `frame_times` は撮影時刻（ミリ秒）のリストです。
   `samples` は `(記録時刻, 電流値)` のリストで、記録時刻は重複せず昇順です。
2. 各撮影時刻について、時刻差の絶対値が最小のサンプルを選んでください。
   時刻差が同じ場合は、記録時刻が早い方を選んでください。
3. 時刻差が `max_gap_ms` 以下なら選んだタプルを、上回る場合や
   サンプルが空の場合は `None` を結果に入れてください。
4. `frame_times` の入力順を保ったリストを返してください。
   同じサンプルを複数の画像に対応付けても構いません。
5. サンプルの時刻だけを取り出したリストを最初に作り、
   標準ライブラリの `bisect_left` で各撮影時刻の挿入位置を探してください。

## 入力例

frame_times = [80, 20, 40, 60, 110]
samples = [(20, 120), (60, 180), (90, 150)]
max_gap_ms = 20

## 期待する戻り値

[(90, 150), (20, 120), (20, 120), (60, 180), (90, 150)]

撮影時刻 40 ms は 20 ms と 60 ms の中間なので、早い方を選びます。
撮影時刻 110 ms は 90 ms との差がちょうど 20 ms なので、対応付けます。

## 完了条件

上の例に加え、`frame_times = [111]` なら `[None]`、
`frame_times` が空なら `[]`、`samples` が空なら各画像に `None` が
返ることを確認してください。
