# Strict Integer Parser

使用言語: C++17以上
目安: 15〜20分

## 目的
std::from_charsを使い、文字列全体が有効な整数かを判定する処理を実装してください。

## 課題
文字列を受け取り、整数への変換結果を表示するプログラムを作成してください。
変換できない場合は、その理由を表示します。

## 要件
1. 次の関数を実装してください。
   void printParseResult(const std::string& text);

2. 整数への変換にはstd::from_charsを使用してください。
   変換先の型はint、基数は10とします。

3. 以下の優先順位で結果を判定してください。
   - 数字を1文字も読み取れない: INVALID
   - intの範囲を超える: OUT_OF_RANGE
   - 変換後に未処理の文字が残っている: TRAILING_CHARACTERS
   - 文字列全体を変換できた: OK: 整数値

4. 空白の除去や入力の補正は行わないでください。
   先頭のマイナス記号は許可しますが、プラス記号は許可しません。

5. 入力はコード内のstd::vector<std::string>に用意して構いません。
   表示形式は「"元の文字列" -> 判定結果」としてください。

## 入力例
"42"
"-17"
"003"
"12abc"
" 42"
"+5"
""
"999999999999999999999999"

## 期待出力
"42" -> OK: 42
"-17" -> OK: -17
"003" -> OK: 3
"12abc" -> TRAILING_CHARACTERS
" 42" -> INVALID
"+5" -> INVALID
"" -> INVALID
"999999999999999999999999" -> OUT_OF_RANGE

## ヒント
- 必要なヘッダーは<charconv>です。
- 戻り値のecでエラーの種類を確認できます。
- 戻り値のptrで、どこまで読み取れたか確認できます。

## 完了条件
期待出力と一致し、「一部だけ変換できた場合」と
「文字列全体を変換できた場合」を区別できれば完成です。
