# 今日のC++課題：`std::atomic`によるスレッドセーフなカウンタ

## 難易度
中級

## 想定時間
20～30分

## 使用する機能
- `std::atomic`
- `std::thread`
- `fetch_add()`
- `compare_exchange_weak()`

## 問題

複数のスレッドから安全に操作できる、上限付きカウンタクラス
`LimitedCounter` を実装してください。

### `LimitedCounter`の仕様

次のメンバを持たせてください。

- 現在値を保存する `std::atomic<int>`
- カウンタの上限値を保存する `int`
- 現在値を返す `get()`
- カウンタを1増やす `increment()`

`increment()`には次の条件があります。

- 現在値が上限未満なら1増やし、`true`を返す
- すでに上限に達している場合は変更せず、`false`を返す
- 複数スレッドから同時に呼ばれても、上限を超えてはいけない
- `std::mutex`は使用しない

## 動作確認

`main()`で次の処理を実装してください。

1. 上限値を `100000` として `LimitedCounter` を生成する
2. 4本のスレッドを起動する
3. 各スレッドから `increment()`を50000回呼び出す
4. 全スレッドの終了後、現在値を表示する

## 期待される出力

現在値は必ず上限と一致し、上限を超えないこと。

```text
Counter: 100000
```
