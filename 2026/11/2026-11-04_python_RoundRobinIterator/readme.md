# Round Robin Iterator

使用言語: Python
目安: 15〜25分

## 課題
複数のリストから要素を1つずつ順番に取り出すジェネレータ関数
round_robin(groups) を実装してください。

例えば、3つのリストがあれば、1番目→2番目→3番目→1番目…
の順に取り出します。要素を使い切ったリストは飛ばしてください。

## 要件
1. yieldを使い、要素を1つずつ返してください。
2. 各リスト内の要素の順序を維持してください。
3. 空のリストは飛ばし、入力全体が空なら何も返さないでください。
4. 入力のリストを変更しないでください。
5. 全要素をまとめた結果リストを関数内部で作らないでください。

## 入力例
groups = [
    ["A", "B", "C"],
    [1],
    [],
    ["x", "y"]
]

print(list(round_robin(groups)))

## 期待出力
['A', 1, 'x', 'B', 'y', 'C']

## 追加の確認例
list(round_robin([]))
→ []

list(round_robin([[], []]))
→ []

list(round_robin([[1, 2], [3, 4]]))
→ [1, 3, 2, 4]

## 完了条件
上記の結果が得られ、実行後も入力のリストが変化していないことを
確認してください。
