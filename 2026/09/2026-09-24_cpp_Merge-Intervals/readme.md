# 今日のC++課題：MergeIntervals

## 問題

予定の時間帯を表す `Interval` を用意し、重なっている時間帯をまとめる関数 `mergeIntervals` を実装してください。

```cpp
struct Interval {
    int start;
    int end;
};

std::vector<Interval> mergeIntervals(std::vector<Interval> intervals);
```

各時間帯は `[start, end)` とします。`start` は含み、`end` は含みません。このため、`[1, 3)` と `[3, 5)` は重なりません。

## 条件

- 入力の順序は任意です。
- 各要素は `start < end` を満たします。
- 戻り値は開始時刻が小さい順にしてください。
- 元の入力は変更しなくて構いません。

## 入出力例

入力：`{{5, 8}, {1, 4}, {3, 6}, {10, 12}}`  
出力：`{{1, 8}, {10, 12}}`

入力：`{{3, 5}, {1, 3}}`  
出力：`{{1, 3}, {3, 5}}`

入力：`{}`  
出力：`{}`

## ヒント

開始時刻で並べ替えてから、結果の最後の時間帯と次の時間帯を比較すると実装しやすいです。
