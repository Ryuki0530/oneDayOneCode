# ServoLoadIntervals

- 日付：2026-11-26
- 使用言語：C++17
- 所要時間の目安：15〜25分

## 課題

サーボの負荷ログから、負荷がしきい値以上の状態が一定回数以上続いた区間を抽出してください。1回の走査で、各区間の開始位置・終了位置・最大負荷を求める練習です。

## 実装要件

1. `findLoadIntervals` 関数を実装してください。引数は負荷の配列 `const std::vector<int>& loads`、しきい値 `int threshold`、区間の最小サンプル数 `std::size_t minSamples` です。`minSamples` は1以上とします。
2. `threshold` 以上の値が連続するひとまとまりを1区間とします。連続したサンプル数が `minSamples` 以上の区間だけを結果に含めてください。
3. 区間を表す `LoadInterval` 構造体を定義し、開始インデックス `start`、終了インデックス `end`、区間内の最大負荷 `peakLoad` を持たせてください。インデックスは0始まりで、終了位置も区間に含みます。
4. 結果は開始位置の昇順で `std::vector<LoadInterval>` として返してください。空入力や該当区間がない場合は、空の `vector` を返します。ログの末尾まで続く区間も対象です。
5. 負荷ログは先頭から1回だけ走査してください。`main.cpp` の `main` にサンプルを用意し、各区間を `start end peakLoad` の順に1行ずつ表示してください。

## 入力例

- loads = {25, 20, 4, 22, 3, 20, 31, 24}
- threshold = 20
- minSamples = 2

## 期待出力

    0 1 25
    5 7 31

インデックス3の負荷 `22` は、1サンプルしか続かないため結果に含まれません。

## 完了条件

サンプルが期待出力と一致することを確認してください。さらに、空入力で結果が空になることと、`loads = {20}`、`threshold = 20`、`minSamples = 1` で `0 0 20` が得られることを確認してください。
