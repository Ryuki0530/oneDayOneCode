# 今日のC++課題：イベント通知システム

## 目的

`std::function` とラムダ式を使用して、複数の処理を登録・実行できるイベント通知システムを作成してください。

## 使用する規格

C++17

## 要件

`Event` クラスを作成してください。

### Eventクラス

以下のメンバ関数を実装します。

- `subscribe()`
  - コールバック関数を登録する
  - 登録したコールバックを識別するための整数IDを返す

- `unsubscribe()`
  - 指定されたIDのコールバックを削除する
  - 削除できた場合は `true`
  - IDが存在しない場合は `false` を返す

- `notify()`
  - 登録されているすべてのコールバックを呼び出す
  - 各コールバックには整数値を渡す

## コールバックの型

コールバックは、次の形式の関数を登録できるようにしてください。

void callback(int value);

`std::function<void(int)>` を使用します。

## main関数で行うこと

1. `Event` オブジェクトを作成する
2. 次の2つのコールバックをラムダ式で登録する
   - 受け取った値をそのまま表示する
   - 受け取った値の2倍を表示する
3. `notify(10)` を実行する
4. 1つ目のコールバックを解除する
5. `notify(20)` を実行する

## 実行例

Value: 10
Double: 20
Double: 40

## 制約

- コールバックの保存には `std::unordered_map` を使用する
- コールバックの型には `std::function<void(int)>` を使用する
- 登録IDは1から始まり、登録のたびに1増加させる
- グローバル変数は使用しない

## ビルドコマンド

g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o main
