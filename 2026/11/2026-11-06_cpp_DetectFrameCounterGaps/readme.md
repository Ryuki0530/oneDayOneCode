# DetectFrameCounterGaps

- 使用言語 C++17
- 目安 15〜20分

## 課題

受信した通信フレームの連番を調べ、フレームの欠落や重複を検出するプログラムを書いてください。連番は送信元IDごとに管理し、15の次は0に戻ります。

## 実装要件

1. フレームは送信元IDと連番を持ちます。連番は0〜15の整数です。
2. 各IDの最初のフレームは比較の基準として記録します。
3. 同じIDの前回の連番と比べ、同じ値なら `DUPLICATE`、次に来るべき値なら正常、それ以外なら `GAP` と判定します。
4. `GAP` では、期待した連番と実際に受信した連番を表示します。判定後は、受信した連番をそのIDの比較基準にします。
5. 異常は受信順に表示します。正常なフレームについては出力しません。

## 入力例

各行は「送信元ID 連番」です。データは `main` 内に `std::vector` で用意して構いません。

0x100 14
0x200 3
0x100 15
0x100 0
0x200 5
0x100 0
0x200 6

## 期待する出力

GAP 0x200 expected=4 actual=5
DUPLICATE 0x100 counter=0

## 完了条件

サンプルの出力が一致し、15から0への切り替わりと、欠落検出後の5から6への遷移が正常と判定されることを確認してください。入力が空の場合は、出力がないことも確認してください。
