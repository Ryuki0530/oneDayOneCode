# BitCount
使用言語: C
目安: 5〜10分

## 課題
符号なし整数に含まれる「1のビット」の個数を数えてください。

## 要件
1. 次の関数を実装してください。
   unsigned int count_bits(unsigned int value);
2. ビット演算を使い、組込みのビット数カウント関数は使わないでください。
3. main関数で以下の値を確認し、値と結果を表示してください。
4. 入力が0の場合は0を返してください。

## 入力例
0, 1, 7, 10, 255

## 期待出力
0: 0
1: 1
7: 3
10: 2
255: 8

## ヒント
value & 1u で最下位ビットを確認できます。
value >>= 1 で次のビットへ進めます。
