# OneDayOneCode - Anomaly Detector

## 問題
センサから取得した時系列データに対して、
移動平均との差を利用して異常値を検出する
プログラムを作成してください。

## 要件
1. detect_anomalies(data, window_size, threshold)
   関数を実装する。

2. 各データについて、直前のwindow_size個の
   データの平均値を計算する。

3. 現在の値と平均との差の絶対値がthresholdを
   超えた場合、異常値と判定する。

4. 異常値のインデックスと値をタプルにまとめ、
   リストとして返す。

5. 過去のデータがwindow_size個に満たない場合、
   判定を行わない。

## 入力例
data = [10, 11, 10, 12, 11, 50, 12, 10, 9, 11]
window_size = 3
threshold = 15

## 出力例
[(5, 50), (6, 12), (7, 10)]

## 制約
- 外部ライブラリは使用しない。
- 平均値の計算にはsum()を使用してよい。
- 異常値も次回以降の平均値計算に含める。

## 学習ポイント
- スライスによる部分配列の取得
- 時系列データの処理
- 移動平均と閾値判定
- 関数による処理の分離
