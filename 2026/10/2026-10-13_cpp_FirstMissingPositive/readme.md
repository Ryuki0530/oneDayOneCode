# First Missing Positive

使用言語: C++17
所要時間の目安: 15〜20分

## 課題
整数の配列から、「含まれていない最小の正の整数」を探す関数を作成してください。
std::unordered_setを使った検索を練習します。

## 実装要件
1. 次の関数を実装してください。
   int firstMissingPositive(const std::vector<int>& numbers);

2. 正の整数とは1以上の整数です。
   0と負の整数は判定対象から除外してください。

3. 同じ整数が複数回登場しても、結果に影響しないようにしてください。

4. 空の配列では1を返してください。
   入力配列の要素数は最大10,000とします。

5. std::unordered_setを使い、ソートせずに実装してください。
   main関数から以下の4例を実行し、結果を表示してください。

## 入力例
{3, 4, -1, 1}
{1, 2, 0}
{2, 2, 5, -3}
{}

## 出力例
2
3
1
1

## ヒント
- std::unordered_set<int>は、重複しない整数の集合を扱えます。
- insert(value)で値を追加できます。
- count(value)は、値が存在すれば1、存在しなければ0を返します。
- 答えの候補を1から順に調べてみてください。

## 完了条件
4つの入力例で期待どおりの結果が得られ、
{1, 2, 3}に対して4を返せれば完了です。
