# Rotate Sequence
使用言語: C++17
目安: 5〜10分

課題:
整数配列を右にK個分だけ循環移動する関数を作成してください。
末尾からはみ出した要素は先頭へ移します。

要件:
1. 関数は void rotateRight(std::vector<int>& values, int k) とします。
2. kは0以上とし、配列の要素数以上の場合にも対応してください。
3. 空配列の場合は何もしません。
4. mainで動作確認してください。入力はコード内に直接書いて構いません。

入力例:
values = {1, 2, 3, 4, 5}
k = 2

出力例:
4 5 1 2 3

完了条件:
上の例に加え、k = 0、k = 7、空配列でも正しく動作すること。

ヒント:
<algorithm>のstd::rotateが利用できます。
