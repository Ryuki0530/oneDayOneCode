# Run-Length Iterator

使用言語: Java
目安: 15〜20分

## 課題
整数配列を指定した個数ずつ取り出す「バッチ分割」を実装してください。
最後に余った要素も、1つのバッチとして返します。

## 実装要件
1. 次のメソッドを作成してください。
   static List<List<Integer>> splitBatches(int[] values, int size)
2. 元の要素の順序を保ち、各バッチの要素数を最大size個にしてください。
3. 空配列の場合は空のリストを返してください。
4. sizeが0以下の場合はIllegalArgumentExceptionを投げてください。
5. 元の配列は変更せず、各バッチは別々のリストにしてください。

## 入力例
values = {10, 20, 30, 40, 50, 60, 70}
size = 3

## 出力例
[[10, 20, 30], [40, 50, 60], [70]]

## 動作確認
- {1, 2, 3, 4}、size=2 → [[1, 2], [3, 4]]
- {1, 2}、size=5 → [[1, 2]]
- {}、size=3 → []
- size=0 → IllegalArgumentException

## 完了条件
Main.javaのmainメソッドから呼び出し、
上記の動作確認をすべて満たせば完成です。
