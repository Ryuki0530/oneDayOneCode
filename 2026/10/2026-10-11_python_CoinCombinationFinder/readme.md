# おつりの組み合わせ検索

使用言語: Python
目安: 15〜20分

## 目的
標準ライブラリ itertools.product を使い、条件に合う組み合わせを探してください。

## 課題
500円、100円、50円の硬貨をそれぞれ最大3枚まで使い、
指定金額をちょうど支払える組み合わせをすべて表示してください。

## 要件
1. find_coins(amount) 関数を実装してください。
2. itertools.product で各硬貨の枚数の組み合わせを生成してください。
3. 該当する組み合わせを、合計枚数の少ない順に表示してください。
   合計枚数が同じなら、500円硬貨、100円硬貨の枚数が多い順にしてください。
4. 組み合わせがなければ「支払い不可」と表示してください。
5. amount は0以上の整数とします。0円はすべて0枚の組み合わせを表示してください。

## 入力例
amount = 650

## 出力例
500円: 1枚, 100円: 1枚, 50円: 1枚 / 合計3枚
500円: 1枚, 100円: 0枚, 50円: 3枚 / 合計4枚

## 動作確認
amount = 30
出力: 支払い不可

amount = 0
出力: 500円: 0枚, 100円: 0枚, 50円: 0枚 / 合計0枚

## ヒント
from itertools import product

product(range(4), repeat=3)
で、0〜3の整数を3つ並べた全64通りを生成できます。

## 完了条件
650円、30円、0円の結果が上記と一致すること。
