# Round Robin Printer

使用言語: C++17
目安: 15〜25分

## 目的
std::queueを使い、複数の印刷ジョブを順番に処理する仕組みを実装してください。

## 課題
プリンターは、先頭のジョブを最大3ページ印刷します。
印刷が残っていれば、そのジョブを列の最後に戻します。
すべてのジョブについて、この処理を繰り返してください。

## 実装要件
1. 印刷ジョブを、名前と残りページ数を持つ構造体で表してください。
2. ジョブをstd::queueで管理し、登録順に処理してください。
3. 1回の処理で印刷するのは最大3ページです。
   残りが3ページ未満なら、残りすべてを印刷します。
4. 処理するたびに、名前・今回の印刷枚数・残りページ数を表示してください。
   完了したジョブは列へ戻さず、完了順も記録してください。
5. ページ数は正の整数とします。
   ジョブが空の場合は「No jobs」と表示して終了してください。

## 入力例
以下のジョブをコード内で順番に登録してください。

A: 7ページ
B: 2ページ
C: 4ページ

## 期待出力
A: printed=3, remaining=4
B: printed=2, remaining=0
C: printed=3, remaining=1
A: printed=3, remaining=1
C: printed=1, remaining=0
A: printed=1, remaining=0
Completed: B C A

## 完了条件
・入力例と同じ処理順と完了順になること。
・3ページちょうどのジョブが、1回で完了すること。
・ジョブが1件の場合と、空の場合も正しく動作すること。
