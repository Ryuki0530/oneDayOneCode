# InsertSorted

## 問題

昇順にソートされた `std::vector<int>` に対して、
新しい値を追加しても昇順の状態を維持する関数を実装してください。

以下の関数を作成してください。

```cpp
void insertSorted(std::vector<int>& values, int value);
```

ただし、以下の条件を満たしてください。

- `std::sort` を使用してはいけません。
- `std::lower_bound` を使用してください。
- 同じ値がすでに存在する場合、その値より前に新しい値を挿入してください。

## 初期データ

```cpp
std::vector<int> values{
    10,
    20,
    30,
    40,
    50
};
```

次の値を順番に追加してください。

```text
25
10
60
35
```

## 出力例

```text
10 10 20 25 30 35 40 50 60
```

## ヒント

`std::lower_bound` は、指定した値以上となる最初の要素を指すイテレータを返します。

そのイテレータを `std::vector::insert()` に渡すことで、
ソート状態を維持したまま要素を追加できます。

## 今回のポイント

```cpp
std::lower_bound(begin, end, value)
```

は「`value` を挿入するならどこか？」を二分探索で探せます。

たとえば、

```text
10 20 30 40 50
```

に `25` を探すと、`30` の位置を指すイテレータが返ります。

今回は `lower_bound()` が返したイテレータと
`std::vector::insert()` をどう組み合わせるかを意識して実装してください。
