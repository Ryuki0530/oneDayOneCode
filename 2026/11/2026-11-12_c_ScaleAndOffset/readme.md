# ScaleAndOffset

使用言語: C11（x86-64向けGCC / MinGW-w64）
目安: 20〜25分
ファイル: main.c

## 目的
インラインアセンブリで、Cの変数とレジスタの間の値の受け渡しを学びます。

## 課題
符号なし32ビット整数 x に対して「x × 8 + 13」を計算する
次の関数を実装してください。

uint32_t scaleAndOffset(uint32_t x);

## 実装要件
1. 関数内の計算には、GNU形式の __asm__ を1つ使ってください。
2. 8倍は左シフト命令 shll、13の加算は加算命令 addl で行ってください。
   C側で計算結果を求めることは禁止します。
3. 読み書きするオペランドには "+r" 制約を指定し、
   フラグの変更を "cc" クロバーで伝えてください。
4. 32ビットを超えた分は切り捨てます。
   main関数ではCだけで計算した値と比較し、assertで検証してください。

## 使用するヘッダー
- stdint.h: uint32_t
- inttypes.h: PRIu32
- stdio.h: printf
- assert.h: assert

uint32_tの表示例:
printf("%" PRIu32 "\n", value);

## 入力例
標準入力は不要です。次の値をコード内に用意してください。

0
1
10
536870912
4294967295

## 期待出力
0 -> 13
1 -> 21
10 -> 93
536870912 -> 13
4294967295 -> 5

## 構文のヒント
次は「5を加える」別の処理の例です。

__asm__(
    "addl $5, %[value]"
    : [value] "+r" (value)
    :
    : "cc"
);

- "+r": 値をレジスタに置き、入力と出力の両方に使います。
- %[value]: 名前を付けたオペランドを参照します。
- "cc": CPUのフラグが変更されることを伝えます。
- $5: 即値の5です。
- 複数の命令は、文字列内の \n\t で区切れます。

## ビルドと実行（VSCodeのPowerShell）
gcc -std=c11 -Wall -Wextra -O0 main.c -o main.exe
.\main.exe

最適化を有効にした場合も確認してください。

gcc -std=c11 -Wall -Wextra -O2 main.c -o main.exe
.\main.exe

## 完了条件
- 5つの入力すべてで期待出力と一致する。
- -O0と-O2の両方でassertが成功する。
- "+r" と "cc" の役割を説明できる。
