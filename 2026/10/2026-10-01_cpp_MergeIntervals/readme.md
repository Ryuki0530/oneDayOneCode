# MergeIntervals

## 課題
開始時刻と終了時刻で表された複数の区間を、重なりがなくなるようにまとめてください。

今回は、終了時刻と次の開始時刻が同じ場合も結合します。
例：`[1, 3]` と `[3, 5]` → `[1, 5]`

## 入力データ
```cpp
struct Interval {
    int start;
    int end;
};

std::vector<Interval> intervals{
    {8, 10},
    {1, 3},
    {15, 18},
    {2, 6},
    {10, 12}
};
```

## 実装する関数
```cpp
std::vector<Interval> mergeIntervals(std::vector<Interval> intervals);
```

## 要件
- 開始時刻の昇順に並べ替えてから処理してください。
- 重なる区間を結合し、結果を開始時刻の昇順で返してください。
- 空の入力では空の `std::vector` を返してください。
- 各区間は `start <= end` を満たすものとします。
- `main()` で関数を呼び出し、結果を表示してください。

## 出力例
```text
[1, 6]
[8, 12]
[15, 18]
```

## ヒント
- 並べ替えには `std::sort` とラムダ式を使えます。
- 次の区間の開始時刻が、結合中の区間の終了時刻以下なら結合できます。
- 結合後の終了時刻は、2つの終了時刻の大きい方です。
- `std::max` は `<algorithm>` に含まれています。

## 確認ケース
1. 空の入力 → 空の結果
2. `{1, 2}, {3, 4}` → 2区間のまま
3. `{1, 5}, {2, 3}` → `{1, 5}`
4. `{1, 2}, {2, 3}, {3, 4}` → `{1, 4}`
