# Version Comparator
使用言語: Java
目安: 15〜20分

## 目的
ドット区切りのバージョン番号を、数値として比較する処理を実装してください。

## 実装要件
1. 次のメソッドを実装してください。
   static int compareVersions(String a, String b)

2. 各バージョンをドットで区切り、左から順に整数として比較します。
   aが小さければ-1、等しければ0、大きければ1を返してください。

3. 足りない要素は0として扱います。
   例: "1.2" と "1.2.0" は等しいものとします。

4. 各要素の先頭の0は無視します。
   入力は非負整数をドットで区切った正しい形式とし、
   各要素はintの範囲に収まるものとします。

5. mainメソッドで以下の組を比較し、結果を表示してください。
   入力をコード内に直接記述して構いません。

## 入力例
1.9 と 1.10
2.0 と 2
1.02.0 と 1.2
3.0.1 と 3
0.9 と 1.0

## 期待出力
1.9 vs 1.10: -1
2.0 vs 2: 0
1.02.0 vs 1.2: 0
3.0.1 vs 3: 1
0.9 vs 1.0: -1

## ヒント
String.splitは正規表現を受け取ります。
ドットで区切る場合は split("\\.") と記述します。

## 完了条件
期待出力と一致し、"1" と "1.0.0.0" の比較でも0を返せれば完了です。
