# Wildcard Word Search

使用言語: Python
目安: 15〜20分

## 課題
「?」を任意の1文字として扱い、パターンに一致する単語を探す関数を作成してください。

## 実装要件
1. find_matches(words, pattern) を実装し、一致する単語のリストを返してください。
2. 「?」は任意の1文字に一致します。それ以外の文字は完全一致とし、大文字・小文字を区別してください。
3. 単語とパターンの長さが異なる場合は、一致しないものとします。
4. 結果は入力順に並べ、重複する単語は最初の1件だけ残してください。
5. 正規表現やfnmatchは使用せず、文字を比較して実装してください。

## 入力例
words = ["cat", "car", "cut", "cart", "cat", "Cat", "dog"]
pattern = "c?t"

## 期待出力
["cat", "cut"]

## 動作確認
同じwordsに対し、以下の結果も確認してください。

pattern = "???"
→ ["cat", "car", "cut", "Cat", "dog"]

pattern = "z??"
→ []

## 完了条件
上記の結果が得られ、空の単語リストでは [] を返すこと。
また、空のパターンは空文字列の単語だけに一致すること。
