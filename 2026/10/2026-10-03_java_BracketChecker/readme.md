# Bracket Checker

使用言語: Java
所要時間: 15〜20分

## 課題
文字列に含まれる括弧の対応が正しいか判定してください。
対象は ()、[]、{} の3種類です。

## 実装要件
1. static boolean isBalanced(String text) を実装してください。
2. 括弧の種類と閉じる順序が正しい場合に true を返してください。
3. 括弧以外の文字は無視してください。空文字列も true とします。
4. ArrayDeque<Character> をスタックとして使用してください。
5. main で以下の入力例を順番に判定し、結果を表示してください。
   null の入力は考慮しなくて構いません。

## 入力例
(a + b) * [c - {d / e}]
([)]
(() 
abc
空文字列

※「(()」の末尾に空白があっても結果は同じです。

## 期待出力
true
false
false
true
true

## ヒント
開始括弧を push で保存し、終了括弧が現れたら
スタックの先頭と対応するか確認します。
取り出す前に isEmpty で空かどうか確認してください。

## 完了条件
入力例の結果が一致し、")(" や "(" も false になること。
