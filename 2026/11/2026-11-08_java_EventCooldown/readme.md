# EventCooldown

使用言語: Java
目安: 15〜20分
目的: Mapを使って、同じイベントの短時間での再実行を防ぐ処理を実装します。

## 課題

時刻とイベント名の一覧を順番に処理し、実行できるイベントだけを表示してください。
同じイベントは、前回実行した時刻から指定秒数が経過するまで再実行できません。

## 実装要件

1. 各イベントは「時刻（整数の秒）」「イベント名（文字列）」を持ちます。
   入力は時刻の昇順とし、同じ時刻では入力順に処理してください。
2. 初めて登場したイベントは必ず実行してください。
3. 同じイベントを再実行できる条件は、次のとおりです。
   現在時刻 - 前回実行時刻 >= cooldown
4. スキップしたイベントでは、前回実行時刻を更新しないでください。
5. 実行したイベントを「時刻 イベント名」の形式で表示してください。
   入力が空の場合は何も表示しません。

入力データとcooldownは、コード内に直接記述して構いません。
時刻は0以上、cooldownは1以上とし、不正な入力の処理は不要です。

## 入力例

cooldown = 5

0 LOGIN
1 SAVE
3 LOGIN
5 LOGIN
5 SAVE
6 SAVE
8 LOGIN
10 LOGIN

## 期待出力

0 LOGIN
1 SAVE
5 LOGIN
6 SAVE
10 LOGIN

## 完了条件

- 入力例と同じ出力になること。
- 異なるイベントの実行時刻を個別に管理できること。
- 前回実行からちょうど5秒後は実行できること。
- スキップが続いても、待ち時間が延長されないこと。

## ヒント

Map<String, Integer>で、イベント名ごとの最終実行時刻を管理できます。
