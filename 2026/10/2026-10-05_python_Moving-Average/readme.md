# Moving Average

使用言語: Python
目安: 15〜20分
使用ライブラリ: collections.deque（標準ライブラリ）

## 課題
直近のデータだけを使って平均値を計算する「移動平均」を実装してください。

## 実装要件
1. moving_average(values, window_size) 関数を作成してください。
   valuesは数値のリスト、window_sizeは平均に使う最大データ数です。

2. 各データを読み込むたびに、直近window_size個の平均を計算し、
   結果をリストに追加してください。
   データ数がwindow_size未満の場合は、それまでの全データで平均を計算します。

3. データの保持にはcollections.dequeを使ってください。
   毎回sum()で合計を計算せず、追加・除外する値から合計を更新してください。

4. valuesが空なら空リストを返してください。
   window_sizeが0以下ならValueErrorを発生させてください。
   両方に該当する場合はValueErrorを優先してください。

## 入力例
values = [10, 20, 30, 40, 50]
window_size = 3

## 出力例
[10.0, 15.0, 20.0, 30.0, 40.0]

## 動作の説明
10 → 10 / 1
20 → (10 + 20) / 2
30 → (10 + 20 + 30) / 3
40 → (20 + 30 + 40) / 3
50 → (30 + 40 + 50) / 3

## ヒント
deque.append()で末尾へ追加し、deque.popleft()で先頭を取り出せます。
取り出した値を合計から引くと、直近のデータの合計を維持できます。

## 完了条件
入力例の結果が一致し、空リスト・窓サイズ1・不正な窓サイズでも
要件どおりに動作すれば完了です。
