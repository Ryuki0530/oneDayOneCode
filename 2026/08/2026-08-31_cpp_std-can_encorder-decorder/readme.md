# 今日のC++課題：CANデータのエンコード／デコード

## 概要

車速とモーター温度を、8バイトのCANデータとして格納・復元する関数を作成してください。

今回は、整数を複数バイトに分割するビット演算と、通信データで使われるビッグエンディアンを練習します。

## 使用環境

- C++17
- Windows 11
- VSCode

## データ形式

8バイトのデータを次のように使用します。

| バイト位置 | 内容 |
|---|---|
| 0 | 車速の上位8ビット |
| 1 | 車速の下位8ビット |
| 2 | モーター温度 |
| 3～7 | 未使用（0で埋める） |

### 車速

車速は `0.1 km/h` 単位の符号なし16ビット整数として格納します。

例：

- `123.4 km/h`
- 格納する整数値は `1234`
- 16進数では `0x04D2`
- データには `{0x04, 0xD2}` と格納する

### モーター温度

温度は、実際の温度に40を加えた値として格納します。

例：

- `25 ℃`
- 格納する値は `25 + 40 = 65`

これにより、負の温度も符号なし8ビット整数で表現できます。

## 作成する構造体

次の構造体を使用してください。

    struct VehicleStatus {
        double speed_kmh;
        int motor_temperature;
    };

## 作成する関数

### エンコード

    std::array<std::uint8_t, 8> encode(const VehicleStatus& status);

`VehicleStatus`を8バイトのCANデータに変換します。

### デコード

    VehicleStatus decode(const std::array<std::uint8_t, 8>& data);

8バイトのCANデータから`VehicleStatus`を復元します。

## 条件

- `std::array<std::uint8_t, 8>`を使用する
- 車速の分割と復元には、ビットシフト演算子を使用する
- ビットごとのAND演算子を使用する
- バイト0を上位バイト、バイト1を下位バイトとする
- 未使用領域はすべて0にする
- 入力値は次の範囲内であるものとする
  - 車速：`0.0～6553.5 km/h`
  - 温度：`-40～215 ℃`

## 実行例

入力データ：

    VehicleStatus original{123.4, 25};

エンコード結果：

    04 D2 41 00 00 00 00 00

デコード結果：

    Speed: 123.4 km/h
    Temperature: 25 C

## main関数で行うこと

1. `VehicleStatus`に`123.4 km/h`と`25 ℃`を設定する
2. `encode()`を呼び出す
3. 8バイトのデータを16進数で表示する
4. `decode()`を呼び出す
5. 復元した車速と温度を表示する

## コンパイル例

    g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o main
