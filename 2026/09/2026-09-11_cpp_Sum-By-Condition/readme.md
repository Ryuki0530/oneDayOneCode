# SumByCondition

## 問題

整数の一覧から、条件を満たす値だけを合計するプログラムを作成してください。

今回は `std::accumulate` とラムダ式を使用します。

次の整数列が与えられています。

```cpp
std::vector<int> values{
    12, 5, 8, 21, 14, 3, 10, 7
};
```

この中から **偶数だけを合計** してください。

## 条件

- `std::accumulate` を使用すること
- ラムダ式を使用すること
- `for` / `while` によるループで合計を計算しないこと
- 元の `values` は変更しないこと

## 期待する出力

```text
Sum: 44
```

## ヒント

`std::accumulate` は `<numeric>` に定義されています。

```cpp
std::accumulate(開始位置, 終了位置, 初期値, 処理);
```

通常は単純な加算に使いますが、第4引数にラムダ式を渡すことで、
「条件を満たした場合だけ加算する」といった処理も記述できます。
