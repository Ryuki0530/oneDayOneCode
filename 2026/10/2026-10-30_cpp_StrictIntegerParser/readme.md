# Strict Integer Parser

使用言語: C++17
目安: 15〜25分

## 目的
文字列を厳密に整数へ変換し、変換の失敗をstd::optionalで表現してください。

## 実装要件
1. 次の関数を実装してください。
   std::optional<int> parseInteger(const std::string& text);

2. 文字列全体が10進整数を表す場合だけ、変換したintを返してください。
   - 先頭のマイナス記号は許可します。
   - プラス記号、空白、小数点、数字以外の文字は許可しません。
   - 先頭の0は許可します。

3. 空文字列、マイナス記号だけの文字列、intの範囲外の値は、
   std::nulloptを返してください。

4. 変換にはstd::from_charsを使ってください。
   main関数で各入力を変換し、成功時は数値、失敗時はINVALIDを表示してください。
   空文字列も判別できるよう、入力は二重引用符で囲んで表示してください。

## 入力例
次の文字列をコード内の配列またはvectorに用意してください。

"42"
"-17"
"007"
"12abc"
""
" 8"
"+5"
"-"
"999999999999999999999999"

## 期待出力
"42" -> 42
"-17" -> -17
"007" -> 7
"12abc" -> INVALID
"" -> INVALID
" 8" -> INVALID
"+5" -> INVALID
"-" -> INVALID
"999999999999999999999999" -> INVALID

## ヒント
- 必要なヘッダーは<charconv>と<optional>です。
- std::from_charsの戻り値には、読み取り終了位置ptrとエラーコードecがあります。
- エラーの有無に加え、文字列の末尾まで読み取れたかも確認してください。
- optionalの成否は、格納された整数が0かどうかとは別に判定します。

## 完了条件
期待出力と一致し、"0"と"-0"も変換成功として扱えること。
