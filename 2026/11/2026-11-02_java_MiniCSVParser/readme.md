# Mini CSV Parser

使用言語: Java
目安: 15〜25分

## 課題
ダブルクォートで囲まれた項目に対応する、1行分のCSV解析メソッドを実装してください。

## 実装要件
1. 次のメソッドを実装してください。
   static List<String> parseCsvLine(String line)

2. カンマで項目を区切ります。
   ただし、ダブルクォートで囲まれた中のカンマは区切りません。
   項目を囲むダブルクォートは結果に含めません。

3. 囲まれた項目内の連続するダブルクォート2個は、
   1個のダブルクォートとして扱ってください。

4. 空の項目も保持してください。
   空文字列の入力は、空文字列1個を含むリストとして返します。
   空白は削除せず、そのまま保持してください。

5. 入力は正しい形式で、改行とnullは含まれません。
   囲み用のダブルクォートは項目の先頭と末尾にだけ現れます。
   split、正規表現、外部ライブラリは使わないでください。

## 入力例1
apple,"banana,orange",grape

期待する項目:
1: apple
2: banana,orange
3: grape

## 入力例2
"say ""hello""",,end,

期待する項目:
1: say "hello"
2: （空文字列）
3: end
4: （空文字列）

※「（空文字列）」は説明用の表記です。

## 完了条件
Main.javaにテストデータを直接記述し、
上記2例と空文字列の入力を正しく解析できること。
