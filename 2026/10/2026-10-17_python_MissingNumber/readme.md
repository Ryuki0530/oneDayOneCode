# Missing Number

使用言語: Python
目安: 5〜10分

## 課題
1からNまでの整数のうち、1つだけ抜けたリストから、
欠けている数を求める関数 find_missing(numbers, n) を作成してください。

## 要件
- Nは2以上とし、リストには1からNまでのうちN-1個が入っています。
- 数値の重複はなく、順番は不定です。
- 欠けている整数を戻り値にしてください。
- 不正な入力への対応は不要です。

## 入力例
numbers = [5, 1, 4, 2]
n = 5

## 期待出力
3

## 動作確認
find_missing([2], 2) → 1
find_missing([3, 1, 2], 4) → 4

上記3例がすべて正しく動けば完了です。
