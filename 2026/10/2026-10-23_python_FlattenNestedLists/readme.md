# Flatten Nested Lists

使用言語: Python
目安: 15〜20分

## 課題
入れ子になったリストを、整数だけの平らなリストに変換する関数
flatten(data) を実装してください。

今回は「再帰」を使って、深さの異なるリストを処理します。

## 要件
1. dataの要素は、整数またはリストです。
2. 入れ子の深さにかかわらず、整数を元の順番で取り出してください。
3. 空のリストは読み飛ばしてください。
4. 元のリストは変更せず、新しいリストを返してください。
5. 外部ライブラリは使わず、再帰で実装してください。

## 入力例
data = [1, [2, 3], [], [4, [5, [6]]], 7]
print(flatten(data))

## 出力例
[1, 2, 3, 4, 5, 6, 7]

## 追加の確認例
flatten([])                  → []
flatten([[], [[]]])          → []
flatten([[0], [-1, [2]], 3])  → [0, -1, 2, 3]

## ヒント
isinstance(value, list) で、要素がリストか判定できます。
リストなら同じ関数で処理し、整数なら結果へ追加します。

## 完了条件
すべての確認例で期待した結果が得られ、
呼び出し前後で元のリストが変化していないこと。
