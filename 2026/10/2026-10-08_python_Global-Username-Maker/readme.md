# Global Username Maker

使用言語: Python
目安: 20分
使用ライブラリ: Unidecode

## 課題
世界各国の名前や、装飾された文字からユーザーIDを生成してください。
異なる名前が同じIDに変換された場合は、番号を付けて区別します。

## 準備
VSCodeのターミナルで次を実行してください。

python -m pip install Unidecode

main.pyを作成して実装してください。

## ライブラリの使い方
インポート:
from unidecode import unidecode

使用例:
unidecode("Café") → "Cafe"
unidecode("ＡＢＣ") → "ABC"

文字の意味を翻訳するのではなく、ASCII文字へ近似変換します。

## 実装要件
1. 名前のリストを受け取り、同じ順序でユーザーIDを返す
   make_usernames(names) 関数を作成してください。

2. 各名前をUnidecodeで変換した後、小文字にしてください。
   英字a〜zと数字0〜9以外の連続部分を、
   1つのアンダースコアに置き換えてください。
   最後に、先頭と末尾のアンダースコアを削除してください。

3. 変換結果が空なら、基本IDを「user」にしてください。

4. 基本IDが既に使われている場合は、
   「_2」「_3」…を付けて、まだ使われていないIDを探してください。
   入力由来のIDと番号付きIDが衝突する場合も考慮してください。

## 入力例
names = [
    "José",
    "Jose",
    "JOSÉ!",
    "Müller",
    "Ａｌｉｃｅ",
    "Alice",
    "!!!",
    "",
    "Jose 2",
]

## 期待出力
jose
jose_2
jose_3
muller
alice
alice_2
user
user_2
jose_2_2

## ヒント
- re.sub()で不要な文字の連続部分を置換できます。
- 生成済みのIDの管理にはsetが使えます。
- 「名前ごとの登場回数」だけでは、
  入力由来のIDとの衝突を防げない場合があります。

## 完了条件
入力例から期待出力が得られ、
すべてのIDが空でなく、重複していないことを確認してください。
