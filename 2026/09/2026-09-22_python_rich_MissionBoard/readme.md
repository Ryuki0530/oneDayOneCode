# 今日の課題：MissionBoard

難易度：初級〜中級
目安：20分

宇宙船のミッション一覧を、Richを使ってターミナルに表で表示してください。

## データ

missions = [
    {"name": "月面探査", "priority": 3, "done": False},
    {"name": "通信点検", "priority": 1, "done": True},
    {"name": "燃料補給", "priority": 2, "done": False},
    {"name": "航路計算", "priority": 3, "done": True},
]

## 要件

1. 優先度が高い順に並べて表示する。
2. 表の列を「ミッション」「優先度」「状態」とする。
3. done が True なら状態を「完了」、False なら「未完了」と表示する。
4. 未完了かつ優先度 3 のミッション名を赤色で表示する。
5. 最後に「完了：2 / 4」のように、完了数と全件数を表示する。

## 追加チャレンジ

同じ優先度のミッションは、元の並び順を維持してください。
