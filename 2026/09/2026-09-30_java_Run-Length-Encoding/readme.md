# 今日のJava課題：Run-Length Encoding

連続する同じ文字を「文字＋連続回数」に変換するプログラムを作成してください。

## 仕様

`String compress(String text)` を実装してください。

- 同じ文字が連続した部分を、文字とその連続回数に変換します。
- 連続回数が1の場合は、数字を付けません。
- 空文字列を渡した場合は、空文字列を返します。
- 英大文字・英小文字は区別します。

## 入出力例

入力:  "AAABBCCCCDA"
出力:  "A3B2C4DA"

入力:  "aAAbb"
出力:  "aA2b2"

入力:  ""
出力:  ""

## 条件

`main` メソッドから上記3例を実行し、結果を表示してください。
文字列の組み立てには `StringBuilder` を使用してください。
