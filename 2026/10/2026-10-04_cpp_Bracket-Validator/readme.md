# Bracket Validator

使用言語: C++17
目安: 15〜20分

## 課題
文字列に含まれる括弧の対応が正しいか判定する関数
bool isBalanced(const std::string& text)
を実装してください。

## 要件
1. 対象の括弧は ()、[]、{} の3種類です。
2. 括弧の種類と入れ子の順序が正しい場合にtrueを返してください。
3. 括弧以外の文字は無視してください。空文字列もtrueとします。
4. std::stack<char>を使い、文字列を先頭から1回走査してください。
5. 以下の入力例を順番に判定し、結果を表示してください。

## 入力例
(a + b) * [c - {d / e}]
([)]
{[()]}
a + b
((x)

## 出力例
OK
NG
OK
OK
NG

## ヒント
開き括弧をスタックに積み、閉じ括弧が現れたら、
スタックの先頭にある開き括弧と対応するか確認します。
top()やpop()の前には、empty()で空かどうか確認してください。

## 完了条件
入力例の出力が一致し、空文字列はOK、
閉じ括弧だけの文字列 ")" はNGになることを確認してください。
