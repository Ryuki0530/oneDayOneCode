# Shortest Path in a Maze

使用言語: Java
目安: 20〜25分

## 目的
Queueを使う幅優先探索（BFS）で、迷路の最短移動回数を求めてください。

## 課題
文字列配列で表された迷路を受け取り、スタートからゴールまでの
最短移動回数を返すメソッドを実装してください。

メソッド:
static int shortestPath(String[] maze)

各文字の意味:
- S: スタート
- G: ゴール
- .: 通路
- #: 壁

## 要件
1. 上下左右に1マスずつ移動できます。斜め移動はできません。
2. 壁や迷路の外には移動できません。
3. ゴールに到達できない場合は -1 を返してください。
4. 探索には Queue を使い、同じマスを何度も探索しないでください。
5. Main.javaのmainメソッドから呼び出し、結果を表示してください。

入力は1行以上の長方形とし、SとGがそれぞれ1つ存在するものとします。
入力チェックや標準入力の処理は不要です。

## 入力例1
String[] maze = {
    "S..#",
    ".#..",
    "...G"
};

## 期待出力1
5

## 入力例2
String[] maze = {
    "S#G",
    ".#.",
    ".#."
};

## 期待出力2
-1

## ヒント
- Queueの実装には ArrayDeque が使えます。
- キューには各マスの行番号・列番号を入れます。
- スタートからの距離をint[][]で管理すると便利です。
- マスをキューに追加する時点で訪問済みにしてください。

## 完了条件
上記2例で期待どおりの結果が得られ、
スタートとゴールが隣接する {"SG"} では1を返せれば完了です。
