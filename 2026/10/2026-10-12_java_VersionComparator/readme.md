# Version Comparator

使用言語: Java
目安: 15〜20分

## 課題
「1.4.2」のようなバージョン番号を比較するプログラムを作成してください。
文字列の辞書順ではなく、各部分を整数として比較します。

## 実装要件
1. static int compareVersions(String a, String b) を実装してください。
2. ドットで区切った整数を左から比較し、aが小さければ-1、
   同じなら0、大きければ1を返してください。
3. 足りない部分は0として扱ってください。
   例: 「1.2」と「1.2.0」は同じバージョンです。
4. mainで以下の入力例を比較し、結果を表示してください。

入力は数字とドットのみで、各部分はintの範囲内とします。
空文字や「1..2」などの不正な入力への対応は不要です。
先頭の0は無視します（「01」は「1」と同じ）。

## 入力例
1.9 / 1.10
2.0 / 2
1.2.1 / 1.2
01.002 / 1.2
3.0.0 / 3.0.1

## 期待出力
1.9 vs 1.10: -1
2.0 vs 2: 0
1.2.1 vs 1.2: 1
01.002 vs 1.2: 0
3.0.0 vs 3.0.1: -1

## ヒント
String.splitは正規表現を受け取ります。
ドットで分割するときは split("\\.") を使います。
整数への変換には Integer.parseInt を使えます。

## 完了条件
Main.javaの1ファイルで実装し、期待出力と一致すれば完成です。
